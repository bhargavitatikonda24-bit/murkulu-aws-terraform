\# Murkulu Website – AWS Terraform Project



\## Project Overview

This is a hands-on AWS Cloud Engineering project to deploy a basic website infrastructure using Terraform.



\## AWS Services Used

\- Amazon VPC

\- Public Subnet

\- Internet Gateway

\- Route Table

\- Route Table Association

\- Security Group

\- Amazon EC2

\- Amazon Linux 2023

\- Nginx Web Server



\## Infrastructure

Terraform provisions the AWS networking components and an EC2 instance. EC2 User Data installs and starts Nginx automatically.



\## Tools

\- Terraform

\- AWS CLI

\- AWS

\- Git and GitHub

\- PowerShell



\## Deployment Steps

1\. Configure AWS CLI authentication.

2\. Run `terraform init`.

3\. Run `terraform fmt`.

4\. Run `terraform validate`.

5\. Run `terraform plan`.

6\. Run `terraform apply`.



\## Important

This project creates AWS resources that may incur charges. Review your AWS resources and costs, and destroy resources when they are no longer needed.
